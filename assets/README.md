# Logotypy

- `logo_kola.png`, `logo_rzeszow.png` – wersje jasne (negatyw) używane na ekranie stoiska
- `warianty/` – oryginały oraz logo Rzeszowa z zachowanym pomarańczowym znakiem

Folder jest montowany do kontenera na żywo. Podmiana pliku (SVG/PNG/WEBP o tej samej nazwie)
pojawia się na ekranie w ciągu ok. 30 s, bez przebudowy. Aby użyć kolorowego znaku Rzeszowa,
skopiuj `warianty/logo_rzeszow_kolor.png` jako `logo_rzeszow.png`.
